# Como publicar o projeto

O pacote contém o conteúdo do projeto. A criação do fork, o envio dos arquivos, a submissão na DIO e o compartilhamento social ainda precisam ser realizados na sua conta.

## 1. Fazer o fork

1. Entre na sua conta do GitHub.
2. Abra o [repositório oficial do desafio](https://github.com/digitalinnovationone/lab-natty-or-not).
3. Clique em **Fork**.
4. Selecione sua conta como proprietária.
5. No campo de nome, você pode usar **natural_ou_fake_natty_dio**.
6. Use a descrição curta disponível em [CONTEUDO.md](CONTEUDO.md).
7. Confirme a criação do fork.

O fork mantém a relação com o repositório original, conforme solicitado no enunciado. [Documentação do GitHub](https://docs.github.com/pt/pull-requests/how-tos/work-with-forks/fork-a-repo).

## 2. Extrair o pacote

No Windows, clique com o botão direito no ZIP e selecione **Extrair Tudo**.

O pacote possui seis arquivos no mesmo nível: README.md, PROMPTS.md, ANALISE.md, CONTEUDO.md, COMO_PUBLICAR.md e cafe-quase-real.png.

Essa organização permite selecionar todos os arquivos de uma vez, sem precisar criar pastas no GitHub.

## 3. Enviar os arquivos

Na página principal do **seu fork**:

1. Clique em **Add file → Upload files**.
2. Selecione os seis arquivos extraídos para que fiquem na raiz do repositório.
3. Confira a atualização do README.md existente e a inclusão dos demais arquivos.
4. Use uma mensagem de commit como **Adiciona projeto Café Quase Real**.
5. Confirme o commit. Se você escolher uma nova branch, conclua a incorporação das mudanças na branch principal do seu próprio fork.
6. Abra a página principal e confira se o README mostra a imagem e se os links internos funcionam.

Envie os arquivos extraídos: o ZIP é a embalagem para download. Preserve os nomes dos arquivos, pois os links do README dependem deles.

Guia oficial: [Adicionar um arquivo a um repositório](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository).

## 4. Submeter na DIO

1. Copie o endereço do **seu fork** no GitHub.
2. Use esse endereço no campo de entrega do desafio.
3. Copie o título e a descrição para DIO disponíveis em [CONTEUDO.md](CONTEUDO.md).
4. Conclua a submissão conforme os campos apresentados na plataforma.

## 5. Compartilhar

Use o texto social de [CONTEUDO.md](CONTEUDO.md), adicione o link do repositório publicado e anexe a imagem.

A hashtag do desafio é **#LabDIONattyOrNot**.
